# Micro-video: Patrones de Diseño y Arquitectura (Semana 10)

Este repositorio contiene la demostración práctica de 5 patrones y conceptos de arquitectura de software para la tarea de Desarrollo Web:

1. **Singleton**: Garantiza una única instancia de conexión a la base de datos.
2. **Repository**: Abstrae y maneja la persistencia de datos.
3. **Factory**: Encapsula la creación de objetos de usuario.
4. **MVC (Controlador)**: Maneja la lógica de la petición y coordina componentes.
5. **JWT + Interceptor**: Captura la petición HTTP e inyecta el token de autorización.

## ¿Cómo ejecutar el código?

Asegúrate de tener [Node.js](https://nodejs.org/) instalado en tu equipo y ejecuta:

```bash
node app.js
```
